# Regles de conduite et standards du projet

## Regles de redaction et syntaxe
- Proscription absolue des tirets cadratins (em dashes) et demi-cadratins (en dashes). Seuls les tirets simples (-) et les virgules sont autorises.
- Pas de jargon de redaction assistee par IA ("Delve into", "En conclusion", "Robuste", "Plongeons-nous"). Ton direct, technique et precis.
- Absence totale de badges decoratifs ou d'emojis dans la documentation technique et le code.
- Suppression systematique du code mort et des commentaires non essentiels.

## Directives d'architecture
- Stack: Next.js 15, React 19, TypeScript strict, Payload CMS v3.
- Design: Swiss Design, typographies Bricolage Grotesk et Inter, asymetrie et gestion precise du blanc tournant.
- Optimisation GEO / AIO: HTML semantique exhaustif, tableaux pour les programmes, JSON-LD valide via schema-dts.
